Comment ça marche

Cette page sert à signaler chaque entrée ou sortie de boisson, pour que le stock du Google Sheet reste à jour.

  • Équipe / pôle : indiquez qui fait la saisie (ex : IC, Animation…). C'est obligatoire pour pouvoir enregistrer.
  • Commentaire : facultatif, pour préciser un contexte (ex : réassort avant match).
  • Sortie d'une boisson : cliquez sur − sur la ligne correspondante. Si vous sortez 1 Cola, la ligne Cola doit afficher -1 avant d'enregistrer.
  • Entrée d'une boisson (réassort) : cliquez sur + sur la ligne correspondante.
  • Vous pouvez ajuster plusieurs boissons avant d'enregistrer : rien n'est envoyé tant que vous n'avez pas cliqué sur Enregistrer.
  • Enregistrer envoie tous les mouvements en attente en une seule fois dans le Google Sheet.
  • Annuler remet tous les compteurs à zéro sans rien envoyer.
